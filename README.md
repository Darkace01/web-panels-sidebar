# Zen Sidebar

A Zen Browser mod that gives Zen a Vivaldi / Brave / Edge-style sidebar: a slim icon rail for your pinned web panels, with a resizable panel that opens beside the page.

## Features

- Slim icon rail with hover/active states
- Configurable rail position (left or right)
- Compact mode (icons only)
- Panel width presets

## Install

Once published: Zen Settings > Mods > search "Zen Sidebar" > Install.

Local testing:

```powershell
.\scripts\install.ps1
```

Then fully restart Zen.

## Status

Early scaffold (v0.1.0). Selectors target Zen's built-in web panels and need verification against your Zen version.
